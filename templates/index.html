GOOD TO KNOW

Answers before
you get started.

A few details about the current version of EVALUATE PRO.

Still have a question? Contact us ↗
Can I upload multiple resumes at once? ＋

Not yet. The current Flask application accepts one resume per submission. Bulk resume screening is planned for a future backend update.

Which resume formats are supported? ＋

The form accepts PDF, DOC and DOCX files. Actual extraction depends on the existing backend implementation.

How is the ATS score calculated? ＋

The current implementation uses keyword and skill matching between extracted resume text and the job description. It is not a semantic AI assessment or a guarantee of candidate suitability.

Can I revisit past evaluations? ＋

A persistent screening history is planned. The current interface does not yet provide a connected history dashboard.

Does it support organisation accounts? ＋

Authentication, organisation accounts, job openings and team access are planned for a future backend phase.
